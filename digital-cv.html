Timeline
01
Tuần 1: Nghiên cứu & Design

Lên ý tưởng bố cục, lựa chọn màu sắc chủ đạo và vẽ wireframe cho các trang.

02
Tuần 2: Xây dựng Layout

Sử dụng HTML5 để dựng khung toàn bộ các phần: Intro, Kỹ năng, Dự án, Liên hệ.

03
Tuần 3: Định dạng CSS

Viết CSS tạo kiểu dáng, áp dụng Flexbox/Grid để căn chỉnh và tạo hiệu ứng hover mượt mà.

04
Tuần 4: Responsive Design

Sử dụng Media Queries để cấu hình hiển thị chuẩn trên màn hình máy tính bảng và mobile.

05
Tuần 5: Review & Tối ưu

Nhờ Mentor FUNiX review code, tinh chỉnh lại các selector CSS thừa và tối ưu cấu trúc DOM.

06
Tuần 6: Khắc phục lỗi

Kiểm tra hiển thị chéo trên các trình duyệt Chrome, Safari, Edge để fix các lỗi vỡ layout.

07
Tuần 7: Deploy dự án

Đưa mã nguồn lên GitHub và triển khai web chạy thực tế hoàn toàn miễn phí trên GitHub Pages.

Scopes
IN

Phát triển giao diện tĩnh cho 4 màn hình chính bao gồm: Trang chủ, Thông tin cá nhân, Danh sách kỹ năng và Form liên hệ.

Áp dụng hiệu ứng chuyển động CSS mượt mà và khả năng tương thích hiển thị responsive tốt trên mọi thiết bị di động.

OUT

Không tích hợp hệ thống quản trị admin panel để chỉnh sửa thông tin trực tiếp trên giao diện web.

Không xây dựng cơ sở dữ liệu (Database) để lưu trữ thông tin tin nhắn gửi từ form liên hệ.

Primary

Thiết kế giao diện tối giản nhưng hiện đại để làm nổi bật các kỹ năng lập trình chủ đạo.

Mã nguồn được viết sạch đẹp, phân chia block rõ ràng theo chuẩn sơ khai của Frontend.
